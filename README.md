# OWASP Quick Auditor

A Python-based OWASP Top 10 auditing tool with Cyber Mentor Mode.

## Features

- Security Header Analysis
- Cookie Security Checks
- CORS Analysis
- Directory Listing Detection
- XSS Reflection Checks
- SQL Injection Error Detection
- Security Score Dashboard
- Cyber Mentor Mode
- Interactive HTML Report

## Run

```bash
python3 auditor.py https://example.com
